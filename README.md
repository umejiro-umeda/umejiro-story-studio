# umejiro story studio

このフォルダは、Macに保存してCodexで編集できる静的ホームページ一式です。

## 中身
- index.html
- styles.css

## Macで開く
1. ZIPをダウンロードして解凍
2. フォルダをデスクトップなど分かりやすい場所へ移動
3. index.html をダブルクリックするとブラウザで確認できます

## Codexで開く
ターミナルで `cd ` と入力し、解凍したフォルダをターミナルへドラッグ＆ドロップしてEnter。
その後 `codex` と入力します。

## スマホ用4コマ画像の差し替え
- 現在は `salon-comic.jpg` をスマホ専用の縦4コマ画像として使用しています。
- 同名の画像を置き換えるか、画像を追加して `index.html` の「スマホ用の縦4コマ画像」コメント直下の `href` と `src` を新しい画像パスに変更してください。
- 縦横比を保ち、画面の高さの70%以内で全体を表示します。タップすると別タブで拡大できます。PC用の画像は別管理です。
